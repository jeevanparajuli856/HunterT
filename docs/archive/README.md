# HunterT Archive

This directory holds historical material that is worth keeping but should not stay in the repo root.

## Contents

- `research-plans/`: archived planning documents from earlier research phases
- `experiment-logs/`: point-in-time work logs and run notes
- `papers/`: paper drafts, summaries, and exported PDFs

## Rule

Only move non-code historical artifacts here in the current phase. Live code, datasets, and active pipeline directories remain at their existing paths until a later compatibility-safe migration.
