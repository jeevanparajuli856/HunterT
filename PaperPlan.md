                                                                                                                                                                                                                           
  Title: "HunterT: Language Model-Guided Directory Enumeration — Beyond LSTMs, Toward Deployment"
                                                                                                                                                                                                                           
  Abstract (draft skeleton)                                                                                                                                                                                                
                                                                                                                                                                                                                           
  ▎ Directory brute-forcing remains a critical step in web penetration testing, yet current tools rely on static wordlists. Recent work [Castagnaro et al., AISec'24] showed LSTMs can improve discovery by 969%. We make  
  three contributions: (1) we show their evaluation underestimates LSTM performance by 43% due to single-model, fixed-parameter evaluation; (2) we design DirHunterT, a decoder-only transformer for directory prediction, 
  and find that transformers do NOT outperform LSTMs on this short-sequence task (-7.6%), providing empirical evidence for the continued relevance of recurrent models in security applications; (3) we release HunterT,   
  the first deployable LM-guided directory enumeration tool, and validate it against live targets, demonstrating [X]% improvement over feroxbuster/gobuster in controlled pentesting scenarios.
